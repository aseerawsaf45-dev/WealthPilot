## 2. How to run

```bash
npm test                          # unit + logic (no database needed)
npm run eval:ai                   # AI evals with fake models (no API key needed)
npx tsc --noEmit                  # types
npm run check:security            # security / compliance gates
DATABASE_URL=<Neon test branch> npx tsx --test scripts/integration.mts   # never production
npx tsx scripts/test-catalogue.mts   # regenerates this file
```
